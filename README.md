# 手沖沖煮模擬器

手機優先嘅手沖咖啡模擬器（v2）：調粉量、水量／比例、研磨、水溫、**濾杯＋濾紙**、結構化**豆資訊**、**沖法**同**經典／冠軍配方**，即時產出注水時間表同廣東話小貼士。純靜態頁，無需後端，可離線使用。

## 點樣開

```bash
cd /workspace/brew-simulator
python3 -m http.server 3001
```

瀏覽器打開：<http://127.0.0.1:3001/>

（若 3000 已被佔用，本專案預設用 **3001**。）

## 新功能（v2）

1. **濾杯**：V60 01/02、UFO V3、Kalita Wave 155/185、101/102、Origami／Air S、Hario Switch、Orea V3／V4 Narrow、April、Clever、SOLO、Stagg X、Pulsar 等；以 `<optgroup>` 分組。
2. **濾紙**：Hario／Kalita／Cafec／Sibarist／April／Origami／Melitta／Chemex／Clever 等；跟濾杯軟篩選，可手動覆寫。
3. **Hario Switch**：全開流下／浸泡後開閥／混合；顯示浸泡時間；時間表標示開關閥。
4. **豆資訊（用家記錄）**：填寫豆名／產地／品種／處理法／風味／密度／味道特性／烘焙日期／筆記，撳「儲存呢隻豆」寫入本機；「我嘅豆」列表可載入、更新、刪除。可選「範本」預填欄位；支援匯出／匯入 JSON。載入後會套用同款水溫／研磨啟發式。
5. **沖法**：手沖／濾泡／冷萃／冰咖啡；冷萃顯示浸泡小時、粗研磨、唔同時間表。
6. **經典／冠軍配方**：WBrC 2023–2025、**粕谷哲 4:6 法**（清爽／平衡／濃郁三調性）、Hoffmann、Rao、Kurasu、Switch、Clever、Wave、UFO、日式冰手沖、冷萃、GLITCH、LEAVES TOKYO 等；選中會填參數並顯示「做法教學」卡。
7. **4:6 法**：注水風格揀「4:6 法」或配方「粕谷哲 4:6 法」，再選調性。基準 20g/300ml，粉量／比例改動時各注按線性縮放；累積水量為準、時間係節奏參考。教學卡含 40/60 邏輯同 [Matrix 進階指南](https://www.matrix.com.tw/46-method-advanced-guide-coffee-beans-parameters)。

介面以可摺疊區塊組織：**沖法與配方**、**濾杯與濾紙**、**豆資訊**、**參數**。

## 基準配方

| 項目 | 數值 |
|------|------|
| 粉量 | 15 g |
| 水量 | 250 g（比例 1:16.67） |
| 磨豆機 | Timemore S3 @ 4.9 |
| 豆 | 肯尼亞水洗（硬豆、明亮酸質） |
| 濾杯 | V60 |
| 水溫 | 93°C |
| 注水 | 三段式 |
| 悶蒸 | 45 秒 |

## 縮放規則（同 `app.js` 一致）

1. **鎖比例**：改粉量 → 水量 = 粉量 × 比例。
2. **粉量 &lt; 12g**：研磨建議略細；注水間隔縮短。
3. **粉量 &gt; 18g**：研磨略粗或維持；總時間加長。
4. **處理法／品種**：水洗偏熱；厭氧偏涼溫和；瑰夏溫和。
5. **密度**：硬豆 → 略細＋略高溫；軟豆 → 略粗＋略低溫、溫和。
6. **味道特性**：明亮酸質／發酵感強／花香主導等會微調提示同參數。
7. **UFO V3**：悶蒸約 60 秒，尾段較高攪動。
8. **冰手沖**：熱水約 60–65%，其餘為冰；研磨更細。
9. **冷萃**：粗研磨、12–16h 雪櫃浸泡。
10. **4:6 線性縮放**：各注水量 = 基準表水量 ×（而家總水量 ÷ 300）；時間點唔跟粉量變。

## 檔案結構

```
brew-simulator/
├── index.html
├── styles.css
├── app.js
├── data-beans.js      # 產地／品種／處理法／風味／密度／特性
├── data-recipes.js    # 經典／冠軍配方
├── README.md
└── screenshots/
```

設定存於 `localStorage` 鍵 **`brew-simulator-v2`**（會嘗試從 v1 遷移基本欄位）。

個人豆誌存於 **`brew-simulator-beans-v1`**（陣列：`{id, name, origin, variety, process, flavors[], density, tendencies[], roastDate?, notes?, savedAt}`）。

## 限制

- 研磨建議係經驗法則；S3 ↔ Ode 為粗略對應。
- 冠軍配方係公開資訊整理嘅教學起點，實際賽事細節可能有出入。
- 無後端、無帳號；資料只存本機瀏覽器。
